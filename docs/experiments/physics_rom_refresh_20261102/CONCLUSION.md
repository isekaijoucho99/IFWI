# 本轮结论与成本判断

**精度能够维持，但目前还不能真正加速原 IFWI。**

相同四频率并发配置下，三阶校正＋动态刷新完成5次更新用时18.803秒，同期原FDTD为16.396秒，慢14.7%。初始准备6.011秒另列；加上准备更慢。全部实际使用的5个速度/网络梯度都通过既定门槛；最大波形误差0.3204%、速度梯度0.7445%、原SIREN参数梯度0.2579%。

末态真实FDTD MSE：三阶校正0.0391114801、原FDTD0.0391119756。速度RMSE分别521.474599与521.474173 m/s；两个速度数组的差异RMS0.01477m/s，最大0.16724m/s。这里只说明五步轨迹接近，不是已经收敛或提高最终速度精度。

固定基、每步完整重建和一/二阶校正的全部结果均保留。固定基不合格，二阶校正在一个实际使用的状态中速度/参数梯度分别5.96%/6.63%，也不合格；不能只报它们的较短时间。

三阶动态方法比同并发的每步完整重建(24.057秒)快21.8%，说明缓存校正确实减少了代价，但尚未达到比FDTD更快的主目标。

## 为什么没有净加速

扣除第一个已离线准备状态，原FDTD后4步共13.102秒，动态方法共18.663秒。不能靠第一步便宜来宣称持续加速。

没有触发完整重锚的3个动态更新平均约3.009秒，原FDTD后4步平均约3.276秒，每步仅剩约0.267秒用于摊销重锚。第4次更新触发留出probe，连同已付出的校正/监测/重分解共9.481秒，比普通动态步多约6.472秒。

按这些短测数值作纯成本算术，一次这种重锚需约24.3次普通更新的节省才能摊平；实际不到这个间隔就触发了刷新。该算术不是对长期速度或误差的预测。

## 下一项值得验证的改动

本轮每步仍重做固定192维空间的POD、正交化和投影。下一项更有针对性的假设是：用少量残差补空间增量更新，并复用旧投影，避免每步完整空间重建。必须重新检验原、伴随误差及实际梯度，不能直接放宽门槛以减少刷新。

本轮没有达到同精度净加速，因此没有启动更大规模或1000步训练；也未用新种子测试成功率。现有证据只覆盖单种子、单炮和5次实际更新。
