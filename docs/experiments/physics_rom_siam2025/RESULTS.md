# 实测结果与决策（2026-11-02）

**结论：原方法的固定材料算例已复现；离散适配在建基点能很快、很准确，但本次冻结基未能保持实际 IFWI 更新后的梯度精度，因此不作为当前正式训练的替代正演器。**

## 原作者代码复现

未经改动的作者 Figure 8 固定材料 POD_s + Weeks，在实际 232248 自由度网格上运行，80 维时五个接收点时间记录相对误差为 3.42e-5–4.71e-5。额外四个完整 FEM 频率查询的记录相对误差为 2.2931e-5。Python/MATLAB 小型线性求解误差约 1.02e-15。已核对 40 个原 MATLAB 文件逐字节相同。此处没有重新计时作者 Newmark 对照，所以不复述其墙钟加速比。

## 速度改变后的失效

对2%平滑留出扰动，保留正演空间的192维版本波形误差7.245%、速度梯度误差24.667%；等能量192维版本约7.429%和24.595%。对完整真速度，两者波形误差约100%，有明显的绝对伪梯度。原 FDTD 在真模型处残差和梯度为零，相对梯度误差没有定义。全部27行见 source_data.csv；没有删除失败样本。

## 稳定性与误差来源诊断

背景模型下，96维正演与192维保留正演联合版本的最大已观测 Ritz 极点模分别约0.99999090、0.99999109；逆变换圆半径1.00676866。抽查的极点均在单位圆及积分圆内；这只是 selected Ritz 诊断，不是全谱或全材料稳定性证明。等价递推已与原 FDTD 黑箱状态矩阵及频域传递函数对照。

alias_tolerance 在1e-8、1e-12、1e-16间变化，或取消32 Hz截止，96维正演的速度梯度误差仍约85.7%；192维保留正演版本仍约0.662%。因此在这些背景测试中，严重的梯度问题不能简单归因于32 Hz截断或默认圆半径，快照空间及材料覆盖是更主要的实测限制。更强指数去阻尼反而放大波形重建误差。

## 工程判断与后续条件

不接入现有正式训练，不修改已有实验。当前固定基需要在一次典型更新后就校正或刷新，而单次准备约十余秒，超过原 FDTD 一次反传约3秒；如果每步刷新，将失去速度优势，不能把刷新归为可忽略的离线预训练。

若继续，应首先验证物理切空间/多背景建基或残差驱动的局部更新能否在多个真实 Adam 步间保持原、伴随场精度，再测刷新摊销成本。禁止只根据波形误差决定接受，禁止只报建基点的30倍调用耗时比。13/49炮、nt=2632、完整反演和认证后验界尚未验证。
