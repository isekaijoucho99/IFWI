# 方向 C · 同时震源编码如何改变 FWI 后验样本

把多炮合成一炮可以减少一次梯度计算所需的波动方程求解。对后验采样，更难的问题是，在相同计算预算下，省下的求解能否换来更准确的均值、协方差和模式概率。方向 C 用三个算例检验这个问题。二维高斯问题有解析后验，一维层状反射问题可以独立求积，二维地震问题用全炮似然对地质先验样本加权，得到独立的数值参考。

采样流程沿用 DAPS 的去噪、净模型空间条件采样和重新加噪。Taufik 与 Alkhalifah 将这套思路与同时震源 FWI 结合，并报告了二维、三维及实测数据实验。这里选择可检查的冻结先验与小型 CPU 算例，使采样误差、编码误差和离线参考的误差可以分别测量。[DAPS 原论文及项目](https://daps-inverse-problem.github.io/) · [Taufik 与 Alkhalifah 的 FWI 论文](https://arxiv.org/abs/2512.12797)

## 运行与复现

在仓库根目录使用项目的 Python 环境。查看参数并运行方向 C 的测试。

```bash
python -m experiments.direction_c --help
python -m pytest -q verification/direction_c
```

先用高斯问题比较相同的内层步数。对四炮数据，每个粒子每层分配 28 个单炮梯度当量，足以让下面三种方法都走 4 步。全炮法用 16 个当量，宽度为 1 的编码法用 4 个。配对比较可以检验相同步数和步长下的编码效应。

```bash
python -m experiments.direction_c --tiers gaussian \
  --methods full fixed refresh --particles 96 --encoded-rows 1 \
  --inner-steps 4 --budget 28 --sigmas 2 1 .45 .2 --seed 3 \
  --output-dir outputs/direction_c
```

比较相同预算上限时，省略 `--inner-steps`。每种方法执行剩余额度容纳的完整步数。下面的命令同时运行三类算例、两个地震模型和重复数据校准。`--particles` 控制玩具问题的粒子数，`--seismic-particles` 单独控制地震粒子数，`--sbc-particles` 控制每次校准使用的粒子数。每次运行在输出根目录下创建独立子目录。

```bash
python -m experiments.direction_c --tiers gaussian layered seismic \
  --datasets marmousi overthrust \
  --methods full fixed refresh svrg adaptive refresh_wide refresh_half \
  --particles 96 --seismic-particles 24 --budget 28 --sigmas 2 1 .45 .2 \
  --encoded-rows 1 --probes 4 --noise-ratio .2 \
  --importance-per-component 256 --sbc-replicates 32 --sbc-particles 32 \
  --seed 3 --output-dir outputs/direction_c
```

每次运行的 `config.json` 保存参数，`summary.csv` 汇总各算例与方法，启用重复校准后另有 `calibration.json`。各算例子目录中的 `report.json` 记录参考诊断、评分与成本。每种方法的 `<method>.npz` 包含 `latent` 样本、`mean` 和 `quantiles_05_50_95`，`<method>_stages.jsonl.gz` 可逐行查看每个粒子各层的实际步长、编码和预算。非高斯算例的 `reference.npz` 保存参考点与权重，评分直接使用这些权重计算矩和投影距离。

## 从全炮似然到编码梯度

令 $R_f(x)$ 为频率 $f$ 的预测减观测残差矩阵，行表示炮，列表示接收点。同一频率各炮使用共同的接收几何。原始观测每个实部、虚部分量的独立噪声标准差为 $\delta$。将 $S$ 炮编码为 $k$ 个右端时，对源和观测同时左乘 $W$。全炮取 $W=I_S$，随机编码的每个元素独立取 $\pm 1/\sqrt{k}$。这利用了固定模型下波场对震源的线性。[Krebs 等的同时震源反演](https://doi.org/10.1190/1.3230502)

$$
\Phi(x)=\frac{1}{2\delta^2}\sum_f\|R_f(x)\|_F^2,\qquad
\Phi_W(x)=\frac{1}{2\delta^2}\sum_f\|W R_f(x)\|_F^2 .
$$

由于 $\mathbb E[W^\top W]=I_S$，在给定模型 $x$ 时，独立重抽的 $\Phi_W$ 和 $\nabla\Phi_W$ 分别是全炮目标和梯度的无偏估计。固定一次 $W$ 则定义了一个特定的近似目标 $p_W(x\mid d)\propto p_0(x)\exp[-\Phi_W(x)]$。即使每一项的目标无偏，取指数后再平均也会改变结果。这里编码的是原始全炮平方失配。若把编码后的记录当成直接观测，噪声协方差会含有 $WW^\top$。

每个粒子从先验抽取净模型，叠加标准差为 $\sigma_1$ 的独立高斯噪声。第 $j$ 层将当前带噪模型 $z_j$ 去噪，得到固定中心 $c_j=D_{\sigma_j}(z_j)$。从 $x_0=c_j$ 出发，每步执行

$$
x_{\ell+1}=x_\ell-\eta_j\left[\widehat{\nabla\Phi}(x_\ell)
  +\frac{x_\ell-c_j}{\tau_j^2}\right]
  +\sqrt{2\eta_j}\,\xi_\ell,\qquad \xi_\ell\sim N(0,I).
$$

$\tau_j^2$ 是该噪声层使用的标量条件方差。命令行的默认基础步长分别为高斯问题 $0.06\tau_j^2$、层状问题 $0.0015\tau_j^2$、地震问题 $0.035\tau_j^2$。层末将净模型加上标准差为 $\sigma_{j+1}$ 的独立高斯噪声，最后一层直接返回净样本。粒子的布朗噪声、重加噪声与编码使用独立随机数流。相同种子下，各方法在对应的层和步上共享布朗噪声，便于比较。程序采用无 Metropolis 校正的离散 Langevin 更新。

### 为什么逐步刷新仍会改变方差

把单个方向的条件势能写成 $a x^2/2$。若梯度噪声 $e_\ell$ 独立、均值为零、方差为 $v$，一步为 $x'=(1-\eta a)x-\eta e_\ell+\sqrt{2\eta}\xi_\ell$。于是方差满足 $V'=(1-\eta a)^2V+\eta^2 v+2\eta$。在 $0<\eta a<2$ 时，

$$
V_\infty=\frac{2+\eta v}{a(2-\eta a)},\qquad
V_L=V_\infty\,[1-(1-\eta a)^{2L}]\quad (x_0=0).
$$

目标方差为 $1/a$。式中 $v=0$ 给出纯 Euler 离散误差，$v>0$ 时还有正的梯度噪声贡献。实际震源编码的梯度方差随 $x$ 改变，因此这个标量恒等式用于核查机制。固定步长随机梯度 Langevin 的偏差分析可见 Vollmer 等的工作。[Vollmer 等，JMLR](https://arxiv.org/abs/1501.00438)

## 方法与预算

下表按**每个粒子、每层**计算。$L$ 表示实际完成的步数，$P$ 表示先导梯度次数。一个单炮梯度当量在二维地震问题上需要每个同化频率一次正演右端和一次伴随右端。

| 方法 | 层内用法 | 单炮梯度当量 |
|---|---|---|
| `full` | 每步使用完整单位阵 | $SL$ |
| `fixed` | 所有步、层和粒子共用同一组归一化符号 | $kL$ |
| `refresh` | 每步独立重抽 $k$ 行符号 | $kL$ |
| `refresh_wide` | 将每步编码行数加倍，同时减少单步梯度方差和预算内可走的步数 | $2kL$ |
| `refresh_half` | 使用逐步刷新与一半的基础步长 | $kL$ |
| `svrg` | 在中心求一次全炮梯度。首步直接复用，后续用同一个 $W$ 求当前点与中心的梯度差，再加回中心的全炮梯度 | $S+2k(L-1)$ |
| `adaptive` | 在中心用 $P$ 个独立单行编码估计梯度协方差，在本层选定编码宽度和步长 | $P+kL$ |

SVRG 对当前点与中心使用同一组编码，邻近两点的编码误差相关，作差可以降低梯度方差。两点相距较远时，控制变量的收益也可能消失。[Dubey 等的方差缩减 Langevin 方法](https://proceedings.neurips.cc/paper/2016/hash/9b698eb3105bd82528f23d0c92dedfc0-Abstract.html)

对 `adaptive`，$k$ 行独立编码的平均使梯度协方差缩小到单行协方差的 $1/k$。设单行梯度协方差的最大特征值为 $\lambda$。在最大方差方向，编码引入的一步方差与布朗噪声一步方差之比为 $\eta\lambda/(2k)$。程序用先导样本协方差的最大特征值 $\hat\lambda$ 代入，优先选足够的行数，使估计比值低于 `--noise-ratio`。达到全炮开销时可以直接选单位阵，编码噪声随之为零。余下预算只够较窄编码时，程序减小步长。阶段内保持选择固定，后续梯度使用新抽取的编码。先导样本量小、粒子远离中心、协方差方向旋转，都可能让后续实际比值高于中心估计。

记录中的 `budget`、`used`、`unused` 是预算上限、已用和剩余单炮梯度当量。每个阶段的 `costs` 按 `pilot`、`anchor`、`current`、`control` 分项计费，`steps`、`rows`、`operator`、`tau2` 与 `eta` 描述实际运行的链。`pilot_trace` 和 `pilot_lambda_max` 分别给出协方差迹与最大特征值。指定 `--inner-steps` 后，如果预算连请求的步数也容纳不了，程序报错。比较方法时同时看总模拟时间 $L\eta$、求解右端数、LU 分解次数与墙钟时间。同一个模型和频率的多个右端共享分解，右端数量减少的倍数与实际加速比可能相差很大。地震观测合成、参考构建、后验预测的求解成本另计。玩具算例的梯度通过代数运算得到。

## 参考分布与诊断

**线性高斯。** 四炮约束两个潜变量，先验为 $N(0,I)$，观测为 $d=Ax+\epsilon$。令 $H=A^\top A/\delta^2$、$b=A^\top d/\delta^2$，则全炮后验协方差为 $(I+H)^{-1}$，均值为 $(I+H)^{-1}b$。固定编码时将 $A,d$ 换成 $WA,Wd$ 可求得相应近似目标。这个算例能区分固定编码改写目标与有限步采样偏离目标两种效应。

线性算例还在相同的逐层 $\eta,L,\tau^2$ 下精确传播前两阶矩。以固定中心 $c$ 记 $Q=H+I/\tau^2$，全炮条件平衡分布为 $N(Q^{-1}(b+c/\tau^2),Q^{-1})$。连续 Langevin 在时间 $L\eta$ 的衰减矩阵为 $\exp(-L\eta Q)$。离散链则逐步传播增广向量 $(x,c,1)$ 的二阶矩。刷新编码时对符号行枚举，其二阶矩修正随 $1/k$ 缩放。重加噪时将下一层的 $\sigma^2I$ 加到协方差上。报告比较四条路径。

- `exact_conditional` 每层从全炮条件平衡分布抽样。它与解析后验的差异反映有限起始噪声下以带噪先验初始化的影响。
- `finite_time` 使用精确的连续 Langevin 有限时间转移。与上一条路径比较可见内层时间不足的影响。
- `full_ula` 采用全炮 Euler 转移，在相同时间及步数下分离离散化效应。
- `requested` 使用实际指定的全炮、固定编码或刷新编码。与 `full_ula` 的差异衡量匹配日程下的编码影响。随机编码可以产生高斯混合，两个矩相同仍可有不同分布。各项距离使用不同参照，要在对应的路径之间解释。

**一维层状反射。** 固定界面深度，通过一个潜变量改变层慢度。窄带波形的相位可以产生多个后验峰。用嵌套梯形求积计算全炮后验，根据相邻峰之间的密度极小值划分模式。先看有限积分区间外的后验质量上界，以及加密网格对证据与模式概率的影响，再比较粒子在各区间中的占比。模式概率总变差为 $\tfrac12\sum_m|\hat p_m-p_m|$。均值准确的两个粒子集合可以给同一个小模式分配很不一样的概率。

**二维 Marmousi 与 Overthrust。** 每个网格单元有一个实数潜变量 $x$，速度为 $1000+5500\,\mathrm{sigmoid}(x)$ m/s。程序对常密度、带阻尼的频域声波方程使用稀疏 LU 求解。地质先验是 logit 速度空间的等权各向同性高斯混合。混合中心取自两张地质模型的非重叠图块，每张图为中央测试条带另留一块宽度的缓冲区，固定训练种子与图块后各方法共享这份先验。其去噪器是加性高斯污染下的精确条件均值。DAPS 内层将真实的、依赖于 $z_j$ 的混合条件分布近似为以该均值为中心、具有标量方差的高斯分布。即便使用全炮梯度和长链，这项先验近似仍会影响输出。

每个噪声层的 `reference.conditional_approximation` 用独立先验样本和加噪副本检验这项近似。设真实条件先验为 $p(x\mid z)$，标量高斯近似为 $q(x\mid z)$。样本上 $\log p(x\mid z)-\log q(x\mid z)$ 的均值估计先验带噪分布下的平均 KL，报告使用自然对数，并给出蒙特卡洛标准误。同一处的 `conditional_mean_rmse` 检查条件均值实现，`conditional_score_rmse` 比较两种净模型对数密度的梯度。该诊断使用先验抽样，无需地震求解。

地震参考使用**独立的分层先验重要性采样**。从每个混合分量抽取相同数量的新样本，在每个样本上用所有同化频率和原始全炮数据计算 $\Phi$，再取归一化权重 $w_i=\exp[-\Phi_i]/\sum_j\exp[-\Phi_j]$。等权分量、等量抽样使每个原始样本贡献相同的先验权重。这个参考只需要正演，与 DAPS 的步长、去噪和编码策略无关。`--importance-per-component` 控制每个分量的样本数，默认 256。

先检查 `ess` $=1/\sum_iw_i^2$、`ess_fraction` 与 `max_weight`。权重落在少数样本上时，即使总样本数很大，后验矩仍可能波动。程序将每个分量内的奇、偶号样本分别归一化，给出各半的 `split_half_ess`，以及两个加权均值在 logit 速度空间的逐格均方根差 `split_half_mean_rms`。两半接近只能反映已采到区域的稳定性，二者也可能同时遗漏小而重要的后验区域。参考不稳定时，各方法的细小误差差异难以排序。

**从后验到预测。** `mean_error_l2` 衡量相对参考均值的欧氏距离，`relative_covariance_error` 为协方差之差的 Frobenius 范数除以参考协方差范数，`sliced_w1` 为固定方向上投影一维 Wasserstein 距离的均值。模型真值的 `coverage90`、`interval_width90`、`mean_rmse` 衡量 5%–95% 区间覆盖、平均区间宽度和均值重建误差。地震算例的均值图、分位数图和模型真值区间用速度 m/s 表示，分布距离在 logit 潜空间计算。地震预测在未同化的新频率上使用相同炮与接收几何，玩具问题使用原采集方式下的独立重复观测。预测区间加入新的测量噪声，`mean_rmse_sigma` 和 `interval_width90_sigma` 以观测噪声标准差为单位。区间变宽也会提高覆盖率，因而应同时看覆盖、宽度和预测均值误差。

**重复数据校准。** `--sbc-replicates N` 在高斯算例上重新生成 $N$ 组真值和观测。每组内部，各方法使用相同数据。匹配先验条件下，精确后验的独立样本与真值可交换，每个坐标上真值的秩在 $\{0,\ldots,M\}$ 上均匀，$M$ 为每组粒子数。报告保留按坐标统计的秩直方图、覆盖率和宽度。校准比较选中的五种基本方法，以精确高斯采样为对照。先验失配对照将真值生成尺度改变，推断仍采用原先验。此时精确算法也可能出现秩偏移。固定地震真值的逐格覆盖率描述一次重建的空间表现，具有空间相关性。校准推断过程需要独立重复生成数据。小样本秩直方图还应考虑有限重复次数的波动。[Talts 等的 SBC 原论文](https://arxiv.org/abs/1804.06788)

这些结果针对离散算子、指定先验和有限预算。扩展到学习型扩散先验、三维采集、变接收几何或实测数据时，需要重新检查条件先验误差、似然中的噪声模型和参考分布的可靠性。

## 一次等预算复现

以下命令固定数据和采样种子，运行七种设置、两组二维数据以及匹配和错配先验下各 24 组高斯校准实验。

```bash
python -m experiments.direction_c --particles 192 --seismic-particles 64 \
  --importance-per-component 512 --sbc-replicates 24 --sbc-particles 32
```

每个二维模型使用 $8\times12$ 个网格点、4 炮、5 Hz 和 8 Hz 两个同化频率，并用 10 Hz 的独立噪声观测检查预测。各方法均耗尽预算，每个模型、每种方法各用 14,336 个正演右端及 14,336 个伴随右端。全炮法重用同一 LU 分解，分解次数为 3,584，单行逐步重编码为 14,336，因此相同右端数下运行时间仍可能不同。下表为潜空间的投影 Wasserstein-1 距离，数值越小表示与该模型的全炮参考越接近。

| 方法 | Marmousi | Overthrust |
|---|---:|---:|
| 全炮 | 0.396 | 0.387 |
| 固定编码 | 0.374 | 0.320 |
| 逐步重编码 | 0.369 | 0.571 |
| 方差缩减 | 0.641 | 1.078 |
| 自适应编码 | 0.402 | 0.405 |
| 编码行数加倍 | 0.399 | 0.418 |
| 重编码、步长减半 | 0.347 | 0.276 |

每个二维参考各用 32,768 个独立分层先验抽样和 262,144 个额外正演右端。Marmousi、Overthrust 的权重有效样本量分别为 179、206，分半参考均值的逐格 RMS 差为 0.036、0.037 个 logit 单位。这一次运行中，减半步长取得两个模型最小的投影距离。排序取决于数据、采样种子、参考精度和所选指标。例如 Marmousi 上固定编码的留出频率均值预测误差为 1.31 个噪声标准差，减半步长为 1.55。

解析高斯实验里，逐步重编码与全炮更新在同一逐层步长和步数下具有相同的终态均值，两者终态协方差相差 0.0287（Frobenius 范数）。分层反射实验的三个参考模态质量为 39.9%、31.7%、28.4%，自适应编码的 192 个粒子落入各区的比例为 13.5%、49.5%、37.0%。全炮法给第一个模态分配了 12.0%，说明有限内循环也会严重低估该解族。二维先验条件审计在 $\sigma=1$ 时测得真实混合条件到标量高斯近似的平均 KL 为 $68.94\pm0.27$ nats（512 对样本，一个蒙特卡洛标准误）。这些数据支持分别检查内循环、编码与条件先验近似的影响。
