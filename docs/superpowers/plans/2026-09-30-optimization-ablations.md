## 依据与假设

首轮先验直接对 m/s 速度相邻差作惩罚。完整网格初始数据 MSE=0.0406116，lambda 加权先验=0.0304473；加权先验对物理速度的梯度范数是数据梯度的 86.15 倍。先验组深部速度标准差最终仅约 1.17 m/s。以固定尺度 1000 m/s 归一化先验，检查是否解除平滑主导。

旧注意力权重为 1+2 sigmoid(MLP(z))，即使相同主干也改变初始输出。用末层零初始化、固定物理坐标的恒等门控检验这一影响，另以最后隐藏层通道仿射调制作形式对照。两者均不保证优于基线。

旧分层学习率将后层步长提高五倍且结果振荡。本轮将后层降至基础步长的一半，作为保守步长假设，不据真值调参。

## 实现分工

1. 子代理：losses.py + 损失行为测试；保留旧默认。新增 velocity_scale、平滑 Charbonnier 横向先验、Huber 数据目标；始终单独返回原始 data_mse。
2. 子代理：networks.py + 注意力行为测试；新增 depth_residual 与 feature_film，保留 legacy_output。新变体初始输出、主干参数梯度与原网络一致。
3. 主代理：记录、评估、配置及批量运行；记录独立原始 MSE、固定末步指标、速度范围/深部标准差/横向差异，避免常量场伪改善。
4. 独立审查与回归测试后冻结源码，再完整网格运行。

## 预定实验矩阵

全部固定 seed=42、100 次更新、每 10 步评估、94×288、13 炮、1000 时间点、相同观测与四层 256 宽主干，不用 Dropout 或梯度裁剪。每组除声明因素外保持基线设置。

| 名称 | 单独改变 |
| --- | --- |
| baseline | 普通 MSE，Adam 1e-4 |
| depth_weighted_loss | 已有速度梯度深度预条件 |
| attention | 已有非恒等输出注意力（负面对照） |
| attention_residual | 恒等初始化的深度标量门控，gain=1+0.5 tanh(logit) |
| attention_film | 最后隐藏层通道门控，gain=1+0.5 tanh(scale)，shift=0.1 tanh(shift) |
| prior_only | 已有未归一化 TV 先验（负面对照） |
| prior_normalized_tv | velocity_scale=1000，lambda=0.1，横向系数0.1 |
| prior_normalized_charbonnier | 与上一组一致，仅横向核改 sqrt(d²+eps²)-eps，eps=0.001 |
| data_huber | beta=0.1（炮集单位），二次区间等于 r²，尾部为 2 beta abs(r)-beta² |
| layerwise_conservative | 前层1e-4、后层5e-5，无调度 |

使用不同目标选取的 best 不能直接比较总 loss，优先看固定第100步的共同指标，并保留 best 指标。新源版本下重跑旧对照，不拼接不兼容源码的比较合同。首次试验不添加噪声；Huber 在无噪声数据上是否有益属待测假设。
