# DFM 官方代码适配审查

## 来源与版本

- 论文：[Drift Flow Matching, arXiv:2605.17244](https://arxiv.org/abs/2605.17244)。
- 作者项目页：[DFM](https://merry7cherry.github.io/drift-flow-matching/)，链接到[官方源码](https://github.com/merry7cherry/drift-flow-matching)。
- 固定提交：`619663f0e7cbd17e58d98501daaf389d2810077b`。
- 实际采用：[官方 Sinkhorn、漂移场和损失函数](https://github.com/merry7cherry/drift-flow-matching/blob/619663f0e7cbd17e58d98501daaf389d2810077b/image_generation/src/driftfm/methods/drift_flow_matching.py)。六个纯数值函数保留原函数体，项目导入与分类训练器未引入。MIT 许可与说明见 `third_party/drift_flow_matching/`。

## 原理和实测问题

论文训练两时刻映射 `T(x,t,r,c)=x+(r-t)u(x,t,r,c)`。每个条件与时间对构成独立组，在组内比较预测分布与目标时刻分布，构造停止梯度的漂移目标。生成时复用同一网络，可从 0 到 1 一次运输，也可组合多个区间。这里没有“输入地震记录就自动改善反演”的保证；生成先验怎样影响 IFWI 需要额外验证。

旧版与官方发布实现存在以下差异，不能把旧版结果当作官方方法的复现结果：

| 环节 | 旧版原型 | 固定版本官方实现/本次适配 |
|---|---|---|
| 漂移算子 | RMS 距离、逐行 softmax | Euclidean 距离、平衡 Sinkhorn、正负重心差 |
| 匹配损失 | 自定义 0.5 因子，训练时再除像素数 | 官方每样本平方和及自适应权重接口，默认 `norm_p=0` |
| 端点构造 | `x_t` 与 `x_r` 分别抽噪声 | 同一 `(x0,x1)` 构造两时刻状态 |
| 时间采样 | 20% 固定端点，其余自定义均匀采样 | 排序后的两个 logit-normal：`(-1,2.5)`、`(1,2.5)` |
| 推理权重 | 当前模型 | 默认 EMA，衰减 0.999 |
| 默认候选采样 | 当前速度加噪，`t=.8 → 1`，1 NFE | 独立高斯噪声，`t=0 → 1`，4 NFE，固定外部条件 |
| 验证 | 用真实平滑条件做 `.8 → 1` 去噪 | 从 0 开始的 1/2/4 NFE 条件生成；独立验证集固定 4 NFE 选权重 |

独立端点噪声仍有正确的边际分布；它是相对上游有限样本实现的偏差，不单独证明理论目标无效。逐行 softmax 也与论文中介绍的简化经验漂移有关，但并非当前作者发布的分组 Sinkhorn 实现。暖启动可以作为另行说明的消融实验，不能静默冒充官方默认采样。

在固定的 float64 三样本输入上，旧漂移与官方结果的最大绝对差为 `0.6194956262`；旧损失为 `0.3552270520`，官方为 `1.6074898914`。这些差异说明实现不一致，不说明它们能解释全部 FWI 误差。

## IFWI 适配与兼容性

保持原 CNN 与 IFWI 物理求解器，以隔离数学核心修正；官方分类条件改为同组共享的空间平滑条件。论文 Appendix D 允许高维条件下单个观测目标配多个源噪声，故没有把不同模型的空间条件混到同一组。默认组大小由 16 调整为 64、每步 4 组，仍允许按预算配置。

物理梯度投影、2.5% 先验梯度比例、201 步启用、每 5 步注入与实际物理候选审查保持原有配置。它们属于本仓库的反演适配。基线与已有实验输出继续复用、保留。新权重使用 `ifwi_small_dfm_v2`，记录官方提交、算子、配对、EMA 与验证协议；旧权重要求重新训练。

## 验证证据

新增测试用直接执行固定版本上游函数得到的数值夹具，检查漂移、损失、停止梯度、双边边际约束、组隔离、噪声配对、时间分布、跨 NFE 固定条件、从独立噪声开始、权重版本及生成验证。修复前新增测试出现 8 项预期失败；替换核心后对应测试通过。

新增 14 项针对性测试通过，完整回归 **420 passed、2 skipped、2 warnings**。六个引入函数的 AST 与原文件一致，CUDA 漂移与上游逐值相同；64 步 CUDA 接口试跑与真实 Marmousi 的 2 步物理桥接通过，未新增基线训练。两步桥接用于接口正确性，不用于效果评估。详见 `LOCAL_VALIDATION.md`；以下研究边界不由测试通过消除。

## 研究边界

- 独立验证条件来自该独立模型的平滑场；真实反演用当前估计速度的平滑场，条件分布偏移仍存在。验证日志明确区分此范围，并报告平滑条件本身的 RMSE。
- 逐条件生成 RMSE 是当前控制实验的选模指标，不等同于论文图像生成的分布指标，也不证明有后验采样意义。
- CNN 小网络可能不足以表达地质分布；本次未把网络容量变更与核心修复混在一起。
- 受保护的 2.5% 先验方向可能影响较小；修改其强度需要独立验证，不能按 Marmousi 真值调参。
- 数学一致性、运行正确性与最终反演收益是不同结论。旧 RMSE=388.48 m/s 仍是旧协议结果；尚不能声称修正后优于基线。
