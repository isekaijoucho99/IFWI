## 修正依据与实现

旧先验直接使用 m/s 数值，首步加权先验对物理速度的梯度范数是数据项的 86.15 倍，最终深部标准差降至 1.17 m/s。新增固定 1000 m/s 的先验尺度，速度及范围界限同时归一化；另用 Charbonnier 核与 TV 做对照，单调性约束继续关闭。

旧注意力在初始化时放大网络输出。新增恒等初始化的深度标量门控和隐藏特征 FiLM。完整网格实际保存的初始速度与基线逐值一致，最大绝对差均为 0 m/s。新旧门控的激活、增益范围及作用位置也有差异，不能将结果差异单独归因于初始化。参数量分别为基线 198401、标量门控 200642、FiLM 217505。

新增 Huber 数据目标，二次区间等于残差平方，线性尾部阈值 beta=0.1（实际炮集单位）。所有目标始终独立记录普通波形 MSE；固定末步和各自目标选择的 best 分开保存。`loss.data_objective` 决定数据目标，旧 `loss.type` 字段不参与当前目标计算。

## 如何理解这些结果

- 归一化 Charbonnier 相对训练基线：MSE 降低 2.47%，深层 RMSE 降低 1.24%，SSIM 从 0.10508 升至 0.11130。它是本次短跑中几项主要指标较均衡的候选，不是已证实最优方案。
- 两种新注意力相对基线的深层 RMSE 改善不足 1%，SSIM 略低。相对旧注意力有明显改善，但增加参数量尚未带来明确收益。
- Huber 的深层 RMSE 比基线低 21.91%，同时 MSE 高 57.32%、SSIM 更低。不能只按深层 RMSE 宣称整体改善。其 best 是第 90 步（深层 RMSE 1097.34），不同于上表第 100 步的 1102.94。
- 保守学习率的深层 RMSE 降低 5.09%，但 MSE 高 13.40%，SSIM 降至 0.05738；未表现为全面改进。
- 旧先验的较低深层 RMSE 来自接近常量的速度场，波形拟合差。归一化后深部标准差恢复到约 262–264 m/s，避免了这一退化；真值深部标准差约 791.35 m/s，仍有明显差距。

除旧注意力外，共同初始模型的深层 RMSE 为 1004.24 m/s。**所有组训练后的深层 RMSE 都高于各自初始值**。归一化 Charbonnier 高 38.90%，Huber 高 9.83%。均匀初始模型较低的 RMSE 也不代表正确的地质结构；这说明数据拟合、结构误差和模型变化必须一起看。不能将相对训练基线的小幅改善当作正确反演。

下一阶段应先验证基线与归一化 Charbonnier 的长期收敛，再以共同预算和多个种子检验稳定性；Huber 可作为数据拟合与深层误差的权衡对照。尚未执行 4000 步或多种子实验，也不支持统计显著性或真实数据效果结论。

## 模块取舍评估与蓝红配色更新

这里的“性能”主要指反演质量，同时检查波形拟合、全域/深层误差与结构保真度；不按某个模块自己的训练 loss 排名。比较均为 seed=42 的固定第 100 步，不能证明跨种子稳定提升。

| 模块 | 本轮证据 | 当前取舍 |
| --- | --- | --- |
| 先验尺度归一化 | 旧先验深部标准差仅 1.17 m/s，归一化后恢复到 262–264 m/s，波形拟合也明显恢复 | 保留这一修正，防止先验压倒数据项；这不等于已经恢复真实结构 |
| 归一化 Charbonnier | 相对基线 MSE -2.47%、深层 RMSE -1.24%，SSIM 提高；全域 RMSE 从 1062.40 降至 1050.60 m/s | 优先保留为下一阶段候选，当前属于小幅、尚未证实稳定的收益 |
| 归一化 TV | MSE -1.35%、深层 RMSE -0.99%，SSIM 提高；与 Charbonnier 非常接近 | 保留为简单对照；不能凭这点差距认定 Charbonnier 的形式必然更优 |
| 恒等深度门控 / FiLM | 深层 RMSE 分别改善 0.67% / 0.48%，SSIM 均略降；参数量分别增加约 1.13% / 9.63% | 暂不作为默认增强模块，尚无足够收益支持增加复杂度 |
| 深度梯度预条件 | 深层 RMSE -5.82%，但 MSE +1.67%，SSIM 0.10508 → 0.08237 | 可保留为深层误差权衡对照，不是整体提升 |
| Huber 数据损失 | 深层 RMSE -21.91%，但 MSE +57.32%，SSIM 下降，速度图仍明显偏离真值 | 保留为可选对照，当前无噪声实验不支持替代默认 MSE；未验证抗噪收益 |
| 保守分层学习率 | 深层 RMSE -5.09%，但 MSE +13.40%，SSIM 降到 0.05738 | 当前优先级低；不能排除只是更新更慢，需要更长预算才能区分 |
| 旧输出注意力 | 波形 MSE 更低，但深层 RMSE 从 1412.45 升到 1937.75 m/s，结构相似度也下降 | 不建议启用；降低波形误差没有转化为正确结构 |
| 旧未归一化先验 | 近常量场、波形拟合差，即使 RMSE/SSIM 某些数字看起来较好 | 不建议启用 |

因此，现阶段有明确理由保留的是**先验尺度修正**；最值得继续验证的是**基线 + 归一化 Charbonnier**，TV 作为对照。注意力、Huber 与预条件目前都没有证据支持“普遍有效”。没有任何新增模块已经证明稳定提升正确反演能力。

即使归一化先验的几个整体指标改善，左下角 RMSE 仍略高于基线（Charbonnier 2024.75 vs 2023.36 m/s；TV 2027.94 m/s），深层梯度保真指标仍为负。结合所有组深层 RMSE 均高于自身初始化，不能宣布结构恢复成功。训练时间没有显示新增注意力带来加速；当前各一次的总耗时包含评估，也不足以做严格吞吐量排名。

下一轮用于确认真实收益的最小对照应为基线、归一化 TV、归一化 Charbonnier，在相同更长训练预算下使用多个共同种子，固定评估步数，同时报告全域/深层/局部 RMSE、SSIM、梯度保真与原始 MSE。组合模块的收益尚未测量，不能把单模块改善相加。此处为后续验证建议，本次配色更新没有新增训练。

配色已沿用原 `fwi.py` 的 `RdBu_r`（低速蓝色、高速红色），三张速度对照图统一采用原有 1–4.7 km/s 范围；超出范围的值在色条端点显示饱和并用三角标识。曲线也统一使用蓝红色系，并以线型区分。重新从已有原始数组生成四张图并逐图检查，报告生成器重新核验了全部 10 组产物；数值结果和训练检查点不受配色影响。
