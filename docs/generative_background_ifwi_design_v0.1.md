# 生成式背景搜索与波数路径运输：面向隐式全波形反演初始模型问题的课题设计

**课题设计 v0.1**（2026-10-22）

> 本稿把三条思路排成一条主线、一条延伸和一条副线：思路一（生成式背景搜索）是主线，思路二（波数路径 DFM）是延伸，思路三（漂移场块先验）是副线。第 7 节的 P0 已有代码（`genbg/`），其余阶段只给设计。标 **【待核实】** 的内容在投稿前须逐项核对。

## 摘要

隐式全波形反演（IFWI）在本仓库的 13 炮 Marmousi 协议上能否成功，主要由初始背景决定。σ15 背景上直接 IFWI 和残差 IFWI 都发散，smooth400 背景上则收敛；两者速度 RMSE 相近，差在垂直走时。现有的生成式先验 FWI（G2IFWI、PSG、SFM-FWI 等）都把初始模型当作给定，先验只在背景建立后补高波数。G2IFWI 的作者把"早期低波数先验"明确留作未来工作。

本课题研究另一个环节：**在反演开始之前，用生成模型产生大量候选背景，用不需要伴随的低成本物理打分筛选，再用同一生成模型的多步模式细化**。Drift Flow Matching（DFM）的一步运输负责廉价地铺开候选，多步运输负责细化；正演本身是可信的验证器。这把 DFM 的"测试时扩展"与 FWI 的物理验证结合起来。

预期贡献：

1. **背景可用性的物理打分。** 给出不用真值、只用观测数据的打分（初至走时失配、周波跳跃比例、低通失配），并检验它能否在反演之前预测 IFWI 的成败（P0）。
2. **物理验证的测试时扩展。** 用 DFM 的一步模式生成候选、多步模式细化，每一步都由正演打分选择；与"只用 FM""只用一步""不筛选"做等正演预算的对照（P2–P3）。
3. **波数路径运输（延伸）。** 用低通滤波而非高斯噪声定义概率路径，时间轴对应可分辨波数；在频率延拓的阶段之间做波数跳跃，并用下一频带的数据审查（P4）。
4. **漂移场块先验（副线）。** 不训练生成网络，直接用 Drifting 的漂移场比较当前模型的块分布与地质库的块分布，作为正则梯度（P5）。

## 一 问题与证据

### 1.1 本仓库里的失败模式

| 事实 | 来源 |
|---|---|
| 13 炮、σ15 背景：残差 IFWI 1000 次后 RMSE 749.0 m/s（自 518.75 上升） | `docs/initial_model.md` |
| 同协议、σ15：论文的直接 IFWI 自 518.75 升到 835 m/s | `docs/paper_supplement.md`（D1 一节） |
| 同协议、smooth400 背景：直接 IFWI 1000 次后 415.4 m/s | 同上 |
| smooth400 的速度 RMSE 反而更大（537 对 519 m/s），垂直双程走时误差更小（13.5 对 43.6 ms） | 同上 |
| σ22 背景也不通过第 0 步门槛（551 → 约 705 → 1000 次 638） | `docs/initial_model.md` |

结论：决定成败的是背景的运动学（走时），不是速度误差。初始模型问题不是"再调学习率"能解决的，它需要一个**在反演之前**就能判断背景好坏、并能产生好背景的机制。

### 1.2 现有生成式先验覆盖不到这一环

| 工作 | 生成模型进入的位置 | 对初始模型的假设 |
|---|---|---|
| G2IFWI（JGR MLC 投稿稿） | 背景建立后，RED 梯度 $\lambda(v-D(v))$，α≈2.5% | 高斯平滑初值；作者明确说先验不解决周波跳跃，"早期低波数先验"留作未来工作 |
| PSG（arXiv 2609.12899） | 1000 步反向扩散，每步一次物理更新 | 高斯平滑初值 σ=20；Marmousi 缩到 70×190 |
| SFM-FWI（arXiv 2603.13425） | 在线训练流网络，波形失配自监督 | 高斯平滑初值；差初值测试用线性模型 |
| Post-FWI FM（arXiv 2607.23719，Zhang & Alkhalifah） | FWI 之后的细化 | FWI 结果已给定 |
| Probabilistic Inversion with FM（arXiv 2606.31288） | 摊销：数据 → 速度，无物理循环 | 采集几何固定，OpenFWI 64×64 |

本课题的位置：**反演之前**的背景生成与筛选，以及频带之间的波数跳跃。

## 二 相关方法（已核实）

| 方法 | 关键事实（读原文核对） | 对本课题的意义 |
|---|---|---|
| DFM（arXiv 2605.17244） | 双时间运输 $T(x_t,t,r)=x_t+(r-t)u(x_t,t,r)$；一步与多步共享参数；按时间对分组计算漂移场；$n_g$ 在 64 左右饱和，$n_g=1$ 时一步生成失效；条件生成可在单个目标样本下用多个随机源样本 | 一步铺候选、多步细化；源端必须随机 |
| Drifting（arXiv 2602.04770） | 一步生成器；漂移场 = 吸引正样本 − 排斥生成样本，反对称；ImageNet 上没有特征编码器时训练不成功 | 高维目标的主要风险；背景是低维目标，风险小 |
| PnP-Flow（ICLR 2025） | 数据梯度步 → 用高斯 ε 重投影到 FM 路径 → 去噪 | 加噪重投影的先例 |
| G2IFWI | 程序化生成训练集（随机一维剖面 + 横向延拓 + 弹性形变，Kazei 2021），128×128 块 40k；Overthrust RMSE 424 → 310，BP 237 → 210，数据失配不变 | 训练集构造方式；RED 基线 |
| Wasserstein patch prior【待核实：Hertrich 等，2022】 | 块分布匹配正则 | 思路三的最近邻工作 |

初步检索（2026-10-22，三轮）未找到把 Drifting/DFM 用于反问题的工作，也未找到一步生成先验用于 FWI 背景搜索的工作。投稿前须系统检索【待核实】。

## 三 目标与假设

**总目标**：把 IFWI 的成败从"给定初始模型"中解耦出来，在不用真值的条件下得到可用背景，并以等正演预算衡量收益。

| 编号 | 假设 | 检验阶段 | 否证条件 |
|---|---|---|---|
| H1 | 存在只用观测数据的打分，能在反演前预测背景能否让 IFWI 收敛 | P0 | 所有打分与结局的 Spearman ρ < 0.7，或按打分选出的背景失败 |
| H2 | 程序化背景先验 + 打分筛选，能在不用真值时找到可用背景 | P1–P2 | 筛选出的背景在 σ15 协议上仍失败 |
| H3 | DFM 的一步 + 多步组合，在等正演预算下优于只用 FM 或只用一步 | P3 | 优势在等 NFE、等正演次数下消失 |
| H4 | 波数路径跳跃能缩短达标所需的正演 + 伴随次数 | P4 | k\* 不缩短，或跳跃候选几乎全被拒绝 |
| H5 | 漂移场块先验在相同 α 下不劣于 TV，且优于无先验 | P5 | 数据失配上升或 RMSE 不改善 |

## 四 方法

### 4.1 基线与公平性

- **基线**：残差 SIREN IFWI（论文 E2，`parameterization: residual`，零输出初始化），即 $v_\theta=v_0+f_\theta(x)$。与 G2IFWI 的 $v=\text{MLP}+v_{init}$ 同形，不加 hash 编码，不加 FR/SE。
- **协议**：13 炮 Marmousi（94×288，15 m，8 Hz Ricker，1.9 s，自由表面），Overthrust 94×401（20 m）作第二模型。
- **真值只用于生成观测数据与事后评价**。P0 的受控候选由真值平滑得到，这是为了检验打分，不是方法的一部分，结果中单独标注。P1 起的候选一律不含真值信息，训练集排除 Marmousi 与 Overthrust。
- **预算口径**：所有筛选正演都计入成本，统一折算为"更新当量"（一次全炮正演 + 伴随 = 1）。比较达标所需的更新当量 k\* 与墙钟时间 t\*，沿用 `--stop-rmse` 的口径（Marmousi ε = 396.95 m/s，Overthrust ε = 229.75 m/s）。

### 4.2 思路一：生成式背景搜索（主线）

流程：

1. **背景先验**：在低分辨率网格（例如 24×72，4 倍下采样）上训练背景的生成模型。训练样本是程序化模型的慢度平滑结果，平滑尺度随机，覆盖 smooth400 与 σ22 之间的范围。
2. **铺开**：一步生成 N 个候选（N≈64–256），插值回反演网格。
3. **打分**：每个候选做一次全炮正演（无伴随），计算第 4.4 节的打分。正演可放在粗网格、低通频带上进一步降低成本。
4. **细化（测试时扩展）**：取打分最好的 M 个，从 $x_t=(1-t)\varepsilon+t\,x$ 出发做 DFM 多步运输，每一步生成 K 个样本，保留打分最好的一个。这是"best-of-K + 物理验证器"的序贯选择。
5. **反演**：以最终背景启动基线 IFWI。

为什么用 DFM：铺开需要一步、便宜；细化需要多步、准确；两者由同一网络提供。背景是低维、平滑的目标，Drifting 核函数在原始空间（或简单的多尺度池化特征）上就可能有效，避开了高维图像上"必须有自监督特征编码器"的问题。

对照组（P3）：无先验随机扰动搜索；FM 一步；FM 多步（等 NFE）；DFM 一步；DFM 一步 + 多步；不筛选直接取样本均值。

### 4.3 思路二：波数路径 DFM（延伸）

- **路径**：$m_t=\mathcal L_{k(t)}m$，$\mathcal L_k$ 为截止波数 k 的低通。$k(t)$ 由频带与照明给出（$k\approx 2f\cos\theta/v$），与 `training.frequency_schedule` 的各阶段一一对应。
- **运输**：训练 $T(m_t,t,r)$ 生成分辨到 $k(r)$ 的补全。低通真正丢弃了高波数，给定 $m_t$ 后的补全是一个非退化分布；这一点与"以 $m_0$ 为确定性源的线性插值"不同，后者给定 $(m_t,t,m_0)$ 时目标可被代数求出，先验退化为恒等映射。
- **用法**：每个频率延拓阶段结束时，从当前模型一步生成若干候选，用下一频带的数据做一次正演审查；接受则用网络拟合（不需正演）把 INR 移到候选上，拒绝则照常继续。
- **待查**：PSG 引文中 DiffusionFWI 的"wavenumber-aware"扩展与本思路的边界【待核实】；blurring/cold diffusion 在 FWI 中是否已有应用【待核实】。

### 4.4 物理打分（不用真值）

| 打分 | 定义 | 说明 |
|---|---|---|
| `fb_rms_ms` | 观测与合成记录的初至拾取差的均方根（ms） | 同一拾取器作用于两者，系统偏差相消；排除近偏移距道 |
| `cycle_skip_frac` | $\lvert\Delta t\rvert$ 超过半个主周期（8 Hz 时 62.5 ms）的道比例 | 直接对应周波跳跃的判据 |
| `lp3_nmse`、`lp5_nmse` | 3 Hz、5 Hz 零相位低通后的归一化波形失配 | 与多尺度阶段使用同一低通 |
| `full_nmse` | 全频带归一化波形失配 | 对照：预期对周波跳跃不敏感 |

只用于事后分析的真值描述量：速度 RMSE、SSIM、底部垂直双程走时误差（均方根与最大值）。

### 4.5 思路三：漂移场块先验（副线）

当前模型的块（例如 16×16）为负样本，地质库（程序化模型、邻近剖面或井旁剖面）的块为正样本，按 Drifting 的公式计算漂移场 $V=V^+_p-V^-_q$，在速度空间作为正则梯度，经网络反传进入 θ。权重按 G2IFWI 的 α=‖λg_p‖/‖g_d‖ 设定（1–4%），在背景建立后启用。与 TV、G2IFWI 式 FM-RED 做对照。

## 五 实验阶段与通过门槛

| 阶段 | 内容 | 通过门槛（预先登记） | 估计成本 |
|---|---|---|---|
| **P0** 打分能否预测成败 | 19 个受控候选背景（第 7 节），每个跑 E2 400 次更新；比较打分与结局 | 至少一个不用真值的打分与 RMSE 相对变化的 Spearman ρ ≥ 0.7，且该打分选出的背景成功（RMSE 下降 ≥ 15%） | 打分约 19 次正演；反演约 19 × 40 min |
| **P1** 程序化背景先验 | 程序化地质模型生成器（参照 G2IFWI / Kazei 2021），低分辨率背景集；先训 FM 作基线 | 生成背景的统计量（深度梯度、横向变化谱）覆盖 P0 中成功与失败的候选 | 约 1 周 |
| **P2** 无学习筛选的上限 | 在 P1 的先验样本上只做打分筛选（无细化），以 σ15 协议为考题 | 筛选出的背景使 E2 成功 | 约 2 天 |
| **P3** DFM 测试时扩展 | 训练背景 DFM；第 4.2 节对照组；等正演预算比较 | DFM 一步 + 多步优于 FM 同 NFE，且优于无先验随机搜索 | 1–2 周 |
| **P4** 波数路径跳跃 | 先离线：用已存 IFWI 中间状态生成候选，只统计接受率与失配下降；再在线跑 | 离线接受率显著高于 0；在线 k\* 缩短 | 离线数小时；在线一个队列 |
| **P5** 漂移场块先验 | 接入 `spec.prior`，对照 TV、FM-RED | 第三节 H5 | 约 1 周，可与 P1 并行 |

P0 不通过时：思路一的打分环节不成立，转而检查打分定义（例如改用反射窗口的走时）；若仍不成立，思路一降级为"生成先验 + 完整 IFWI 结局"的昂贵搜索，不再作为主线。

## 六 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 初至只覆盖浅中部，看不到决定成败的深部走时 | P0 不通过 | 同时登记低通失配与反射窗口打分；P0 的分析按打分分别报告 |
| 程序化先验与 Marmousi 背景差异大 | P2/P3 找不到可用背景 | 平滑尺度和深度梯度范围放宽；必要时以打分作引导的多步细化弥补 |
| Drifting 核在背景空间上不稳定 | P3 训练失败 | 先在下采样网格的原始空间试；不行则用多尺度池化特征 |
| 方向被抢发（KAUST 组已有 FM 先验工作） | 新颖性下降 | P0–P2 快速推进；以"反演前背景搜索 + 物理验证测试时扩展"为卖点，不以"换用 FM/DFM"为卖点 |
| 筛选成本被低估 | 等预算比较不成立 | 所有筛选正演计入更新当量，并报告墙钟时间 |

## 七 P0 运行说明

代码在 `genbg/`，规格与队列在 `experiments/genbg/`。

### 7.1 候选背景

网格与 `B_E2_smooth400_s3` 相同（Marmousi 4 倍下采样，94×288，15 m）。

| 组 | 候选 | 构造 |
|---|---|---|
| G | `G10` `G15` `G22` `G30` | 速度高斯平滑 σ（格点），reflect，truncate 4；`G15` 即论文背景 |
| S | `S6` `S9` `S14` | 慢度高斯平滑 σ 后取倒数（保持走时） |

### 7.2 命令

在仓库根目录执行（Windows 下把 `python` 换成环境中的解释器）。

生成候选与规格（CPU 即可，结果入库）：

```bash
python -m genbg.candidates --template experiments/paper_supplement/specs/B_E2_smooth400_s3.json --out experiments/genbg/candidates
```

```bash
python -m genbg.make_queue --candidates experiments/genbg/candidates --template experiments/paper_supplement/specs/B_E2_smooth400_s3.json --epochs 400 --out experiments/genbg
```

打分（每个候选一次全炮正演）：

```bash
python -m genbg.score --candidates experiments/genbg/candidates --template experiments/paper_supplement/specs/B_E2_smooth400_s3.json --device cuda:0 --out outputs/genbg/p0_scores
```

反演队列（每个候选一次 E2，400 次更新）：

```bash
python paper_queue.py experiments/genbg/queues/p0_rank.json --out-root outputs/genbg/p0_runs --shared-dir SHARED --wait-idle
```

分析：

```bash
python -m genbg.analyze --scores outputs/genbg/p0_scores/scores.json --runs outputs/genbg/p0_runs --out outputs/genbg/p0_report
```

每个候选使用独立的观测缓存目录（`marmousi_clean_genbg_<id>`），因为缓存身份里含背景哈希；观测本身与背景无关，每个目录约 60 MB。
