# IFWI 时空注意力初步实现

> 历史记录（2026-09-30）：本页的测试、耗时和实验数值来自当时的冻结源码，未在本次源码发布中重新执行。这里的 `baseline` / “原始 IFWI” 是四层 256 宽、seed=42 的方法对照基线，与当前单次入口的四层 128 宽、seed=3 原版参数协议不同。当前用法见[实验使用说明](../experiments/README.md)。历史 `results/` 产物未随仓库发布，文末仅保留路径记录。

这是一轮可解释的机制验证，不是训练完成的断层恢复模型。保留原 SIREN、原波动正演和原始数据。新代码不读取真值来生成注意力。

## 实现

- 四个 opt-in 配置：`st_multiscale`、`st_time`、`st_space`、`st_joint`，另用原始 `baseline` 作共同参照。
- 第 1–30 次更新使用 5 Hz 平滑低通，第 31–70 次使用 8 Hz，第 71 次起全频；频带切换使用绝对更新步数，恢复训练不重启阶段。
- 对预测与观测使用相同的零填充 FFT 滤波，时间维为 `[batch,shot,time,receiver]` 的第三维。无截止频率时严格保持原始数据。
- 时间权重由每炮、每道的时间窗观测能量与限幅相对残差生成。它不是固定的晚到时增益；静默窗不增强。权重脱离计算图，初始为 1，逐步启用，保持正值、有界和均值 1。
- 空间权重作用于 `v_wave` 正演分支的梯度，先验分支不受影响。使用平滑梯度幅值及温和的阶段性深度偏好；当前是梯度响应代理，不是物理照明估计，也未实现跨炮一致性或断层边缘注意力。
- 第一版没有可学习注意力参数、EMA 或自动阶段切换。这样能以明确的状态和恢复语义检验加权机制。没有加入额外先验，以隔离注意力贡献。

## 公平比较

新协议的 best 使用未滤波、未加权的普通波形 MSE 选择。各阶段训练目标不可直接比较。`selection_metric` 与 `selection_score` 存入检查点和摘要；旧 `best_loss` 键保留为该选择分数的兼容别名。

阶段 k 采用更新前的完成步数。同一轮更新前后使用同一阶段；加载最佳模型时使用 `best_update-1` 重建阶段。权重本身会随该模型的残差重算，因此加权目标只用于诊断，不用于跨步排名。

每个日志步保存 `attention_stepXXXXXX.npz`：本轮更新前生成的空间权重、按接收道平均的时间权重、实际速度变化。注意力热图不等于真实模型更新图，SIREN 的共享参数可能使更新扩散。

## 运行

以下示例从仓库根目录使用已安装依赖的 Python 创建新结果；当前源码的输出不替代本页的历史冻结产物。

```powershell
python -X utf8 -u experiments/run_ablation_suite.py --output-dir results/new_spatiotemporal100 --iterations 100 --log-interval 10 --seeds 42 --configs baseline st_multiscale st_time st_space st_joint
python -X utf8 scripts/summarize_spatiotemporal.py --suite results/new_spatiotemporal100
```

固定末步比较原始 MSE、全域/深层 RMSE、SSIM、梯度保真和局部误差，并同时对比原始基线与仅多尺度组。单种子 100 步只用于检验机制和发现失败模式，不支持收敛、真实数据效果或稳定提升的结论。

## 结果

修正版完整跑完 5 组 × 100 次更新，seed=42，94×288 网格、13 炮、1000 时间点。五组进程合计 55.2 分钟；训练调用内各约 624–639 秒。所有组的最佳已评估快照均为第 100 步，下面统一使用固定末步结果。

| 方案 | 原始波形 MSE | 深层 RMSE (m/s) | 深层 SSIM |
| --- | ---: | ---: | ---: |
| 原始 IFWI | 0.0143141 | 1412.45 | 0.10508 |
| 仅多尺度 | 0.0155863 | 1407.60 | 0.07450 |
| 多尺度 + 时间权重 | 0.0168851 | 1367.49 | 0.06353 |
| 多尺度 + 空间权重 | 0.0155635 | 1390.24 | 0.07850 |
| 多尺度 + 时空联合 | 0.0159536 | 1374.29 | 0.06382 |

联合方案相对原始基线：深层 RMSE 降低 2.70%，原始 MSE 增加 11.45%，SSIM 从 0.10508 降到 0.06382。不能认定整体性能提升。相对仅多尺度，空间权重在 MSE、深层 RMSE、SSIM 上都有小幅改善；但这些优势尚不足以超过原始基线的波形拟合和结构相似度。联合方案相对时间权重单独使用，MSE 降低 5.52%，但深层 RMSE 增加 0.50%，也没有全面优于单项的证据。

共同初始模型的深层 RMSE 为 1004.24 m/s，所有末步结果仍更高。近常量初始模型的较低 RMSE 不代表正确地质结构，同样，训练后相对某个对照的改善也不能证明正确恢复。

## 是否符合先背景、后细节的设想

背景定义为完整网格上 sigma=10 cells（150 m）的高斯平滑；细节定义为原模型减该平滑背景，再统一裁取深部计算误差。这是明确的空间尺度诊断，不是断层定位标签。

| 步数 | 基线背景 RMSE | 联合背景 RMSE | 基线细节 RMSE | 联合细节 RMSE |
| --- | ---: | ---: | ---: | ---: |
| 30 | 1261.65 | 1270.49 | 665.55 | 678.09 |
| 70 | 1219.15 | 1134.06 | 679.70 | 701.55 |
| 100 | 1179.18 | 1133.75 | 684.22 | 688.89 |

第 30 步没有出现预期的背景优势；第 70 步开始，联合方案的背景误差低于基线。最终背景误差降低 3.85%，但细节误差仍高 0.68%。从第 70 到第 100 步，联合方案自身细节误差下降了，但没有超过基线，且仍高于自身第 30 步，也没有恢复出与真值相符的断层证据。当前后期只开放全频，没有实现显式断层结构注意力，因此不能把它视为对完整断层分支的验证。

## 注意力是否真的集中在深层

联合组第 30、70、100 步的深部平均空间权重分别为 0.9908、0.9759、0.9377，浅部为 1.0092、1.0241、1.0623。三次快照都没有显示深部平均权重高于浅部；这是对本轮三个快照的诊断，不是对所有更新的断言。

对应的实际深部更新能量占比分别约 47.9%、67.3%、31.7%。第 70 步深部权重更低但更新占比更高，说明共享 SIREN 参数和 Adam 将权重作用重新分配，不能把注意力图当作模型实际更新图。

本轮局部响应代理更容易强调已有较强梯度的位置，无法直接区分“未恢复但有照明的深层”与“缺少约束的区域”。现有证据说明它尚未实现预期的持续深层聚焦；不能由此推断所有时空注意力都无效。

## 后续应验证的改动

优先改进空间权重的依据：用独立照明/敏感度估计对残差响应做有上限的补偿，再引入跨炮和跨迭代一致性。不能直接对弱梯度取倒数，以免放大无信息区域。后期结构分支应依据数据支持的稳定界面候选，而不是仅追随当前模型边缘。

全频切换附近原始 MSE 出现短时上升，建议将平滑频带过渡与当前硬切换单独对照；当前实验未确定该上升的唯一原因。验证时应固定共同更长预算与多个种子，分别比较基线、仅多尺度和联合方案，并继续保留结构及分尺度指标。本轮未执行这些后续改动，也没有证明长期收敛。

## 验证与可复核产物

- 61 项 CPU 测试通过，包含 FFT 数值梯度、炮道隔离、权重边界、初始恒等、真实波动反传、跨阶段断点恢复及 best 选择口径。
- 独立审查发现并修正了深度衰减被归一化抵消的问题：分别构造有界响应权重和深度权重，再在外部按阶段凸组合。均匀梯度测试的权重偏差为 0.0625 → 0.03125 → 0。
- 旧 `ablation100` 在基线第 21 步后主动停止，日志和取消说明保留，未纳入任何比较；正式结果来自 `ablation100_v2`。
- 五组检查点、数组、训练历史、15 个阶段快照、冻结源码和原始输入哈希全部核验通过。五组初始数组逐值一致；重跑基线的初始/末步模型、真值及观测与上一轮逐值一致。
